# GLOW UP מעלה יוסף — קטלוג הזמנות 2026

אתר הזמנות לרענון סטודיו וקליניקות במועצה אזורית מעלה יוסף.
כל עסק נכנס לאתר, מזדהה, בוחר פריטים מתוך תקציב של **₪9,500**, ושולח את ההזמנה —
שנשלחת אוטומטית לשלוש כתובות מייל ונרשמת בגיליון Google מרכזי.

**לינק חי:** https://dafi-k.github.io/glow-up-maale-yosef/

---

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האתר — HTML, CSS ו-JavaScript בקובץ אחד. אין שלב build |
| `apps-script.js` | קוד Google Apps Script — שליחת מייל + כתיבה לגיליון המרכזי |
| `pic/` | 55 תמונות מוצרים בפורמט webp (~7MB) |

## הרצה מקומית

```bash
npx serve
```

חובה שרת HTTP — פתיחה ישירה של `index.html` (`file://`) תחסום את ה-`fetch`
שמטמיע את התמונות בקובץ האקסל.

## הגדרה ראשונית (חד-פעמית)

### 1. גיליון Google מרכזי
צרו גיליון חדש והעתיקו את ה-ID שלו מה-URL:
`docs.google.com/spreadsheets/d/`**`<ה-ID כאן>`**`/edit`

### 2. Apps Script
1. https://script.google.com → **פרויקט חדש**
2. הדביקו את כל התוכן של `apps-script.js`
3. עדכנו את `SHEET_ID` ל-ID מהשלב הקודם
4. הריצו פעם אחת את `setupSheet` מהעורך — יוצר את שלושת הטאבים ומאכלס
   את "ריכוז כמויות". אשרו את בקשת ההרשאות
5. **פרוס** → **פריסה חדשה** → יישום אינטרנט · הפעל כ: אני · גישה: כל אחד
6. העתיקו את ה-Web App URL

### 3. חיבור האתר
ב-`index.html`, החליפו את `PLACEHOLDER_APPS_SCRIPT_URL` בכתובת שהעתקתם.

> ⚠️ אחרי כל שינוי ב-`apps-script.js` יש לפרוס **פריסה חדשה** —
> עדכון הקוד לבדו לא משנה את מה שה-URL הקיים מריץ.

## תחזוקה

### שינוי מחיר או הוספת פריט
ערכו את מערך `PRODUCTS` ב-`index.html`. שדות:

```js
{key:'A1', id:'A1', sku:'M06710-C', cat:'כורסאות',
 desc:'כורסא מסתובבת', color:'אפור', price:2599, img:'A1.webp',
 sizes:[60,70,80],          // אופציונלי — פותח מודאל בחירת קוטר
 note:ILLUSTRATIVE}         // אופציונלי — "התמונה להמחשה בלבד"
```

- `key` חייב להיות ייחודי; `cat` חייב להופיע ב-`CAT_ORDER`
- **אחרי כל שינוי בקטלוג** — עדכנו גם את `CATALOG` ב-`apps-script.js`,
  פרסו מחדש, והריצו `setupSheet` כדי לרענן את טאב "ריכוז כמויות"

### שינוי התקציב
`const BUDGET = 9500;` ב-`index.html` — ובמקביל `var BUDGET = 9500;`
ב-`apps-script.js`. יש גם שלושה מופעים של "₪9,500" בטקסטים במסכים 2–3.

### נמעני המייל
```js
const RECIPIENTS = ['lior@contrast-il.com', 'marketing@contrast-il.com', 'hadas.uzana@gmail.com'];
```
המזמין/ה מקבל/ת עותק ב-CC אוטומטית לפי המייל שהוזן בטופס.

### תמונות
- webp בלבד, ריבועיות ככל האפשר, עד ~500KB
- **שם הקובץ חייב להתאים בדיוק לאותיות** — GitHub Pages רגיש לרישיות
- בלי `+` בשם הקובץ (השתמשו במקף: `L2-P1.webp`)
- הקובץ מומר אוטומטית ל-JPEG בעת ההטמעה באקסל (אקסל לא תומך ב-webp)

## מנגנונים ששווה להכיר

**מתנה אוטומטית** — פריט `PB` (3 ואזות + 3 שרשראות חרוזי עץ) מוגדר בקבוע `GIFT`
ולא נמצא ב-`PRODUCTS`. הוא נוסף אוטומטית לסוף כל הזמנה שיש בה לפחות פריט אחד,
במחיר 0, ומופיע בסיכום, באקסל, ב-PDF, במייל ובגיליון. אין מנגנון בחירה.

**עקיפת מגבלת 8190 התווים** — `parsePostBody` ב-`apps-script.js` מפרסר ידנית את
גוף ה-POST במקום להסתמך על `e.parameter`, שנחתך ב-8190 תווים. זה הכרחי כי ה-base64
של קובץ האקסל ארוך בהרבה. אל תסירו את הפונקציה.

**`mode: 'no-cors'`** — הדפדפן לא יכול לקרוא את תשובת ה-Apps Script, ולכן האתר
מציג הצלחה גם אם השליחה נכשלה בצד השרת. לבדיקת תקלות: Apps Script → **ביצועים / יומנים**.
